# Neon QA Portfolio

A responsive dark/neon portfolio website built with HTML, CSS and JavaScript.

## Customize before publishing
1. Open `index.html`.
2. Replace `Your Name`, `YOUR_USERNAME`, `YOUR_LINKEDIN`, and `YOUR_EMAIL@example.com`.
3. Update the experience, education, certification, and project text so it is accurate for you.
4. Upload `index.html`, `style.css`, and `script.js` to a GitHub repository.

## Publish with GitHub Pages
1. Create a public repository named `YOUR_USERNAME.github.io` (replace with your GitHub username).
2. Upload the three website files to the repository root.
3. Open repository **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Your website will be available at `https://YOUR_USERNAME.github.io` after GitHub Pages finishes deploying.

This template is an original design inspired by modern neon developer portfolios; customize it with your own information and projects.
